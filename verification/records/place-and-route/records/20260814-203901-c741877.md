# Record 20260814-203901-c741877

- **Record ID**: 20260814-203901-c741877
- **Claim**: `docs/baseline.md#place-and-route-baseline-constrained-100-mhz` --
  `modexp.v` (`WIDTH=16`), synthesized unconstrained then placed and routed
  through `klt place-and-route` (OpenROAD) at a 100 MHz clock constraint,
  reaches `stage_reached: "route"` with a routed DEF/GDS, closes 100 MHz with
  positive slack at the nominal `tt_025C_1v80` corner, and is swept across
  every corner in the ratified corner matrix
  (`spec/decision-records/0001-input-domain-interface-and-corner-matrix.md`
  Decision 4). Also substantiates `spec/modexp.md` Decision 2 (clock target)
  and Decision 4 (area target)'s revisit triggers with their first measured
  values.
- **Design provenance**: netlist (post-synthesis, `flow/.klt/synthesize/modexp_synth_tied.v`,
  derived from `rtl/modexp.v` @ `c741877543658a0974a8a90f07cd4b37a7da4aa1` via
  `klt synthesize` + `flow/tie_constants.py` -- see "Run configuration"); the
  routed layout is `layout/modexp.def` / `layout/modexp.gds`.
- **Run configuration**:
  1. `klt synthesize` (engine `yosys`) against `flow/synthesize-modexp.json`
     -- `pdk.cell_library` = `sky130_fd_sc_hd`, `pdk.corner` = `tt_025C_1v80`,
     `constraints.clock_period_ns` = null (unconstrained; reproduces the
     682-cell baseline byte-for-byte).
  2. `python3 flow/tie_constants.py` on the synthesis output -- rewrites bare
     constant-tie literals (`1'h0`/`2'h0` in `mm_p2`/`mm_m1`/`mm_m2`) into a
     real `sky130_fd_sc_hd__conb_1` tie-cell instance (`_tie_zero_`), the
     local substitute for the now-merged-upstream
     [klayout-tools#864](https://github.com/2AMLogic/klayout-tools/pull/864)
     fix -- see `flow/README.md`'s "Known upstream gaps".
  3. `klt place-and-route` (engine `openroad`) against `flow/par-modexp.json`
     -- `floorplan.method` = `utilization` (35%, `aspect_ratio` 1,
     `core_margin_um` 4, `site` `unithd`), `io.layer_h`/`layer_v` = `met3`/
     `met2`, `constraints.clock_port` = `clk`, `constraints.clock_period_ns`
     = 10.0 (100 MHz), `seed` = 42 (pinned, echoed in the raw JSON envelope),
     `target_stage` = `route`, at `pdk.corner` = `tt_025C_1v80` (nominal).
  4. `flow/run-corner-sweep.sh` -- the identical request from step 3, only
     `pdk.corner` varied, run independently for each of the 18 corners in
     Decision 4's ratified corner matrix (`ff_100C_1v65`, `ff_100C_1v95`,
     `ff_n40C_1v56`, `ff_n40C_1v65`, `ff_n40C_1v76`, `ff_n40C_1v95`,
     `ff_n40C_1v95_ccsnoise`, `tt_025C_1v80`, `tt_100C_1v80`,
     `ss_100C_1v40`, `ss_100C_1v60`, `ss_n40C_1v28`, `ss_n40C_1v35`,
     `ss_n40C_1v40`, `ss_n40C_1v44`, `ss_n40C_1v60`,
     `ss_n40C_1v60_ccsnoise`, `ss_n40C_1v76`).
